# 화면 명세서

와이어프레임과 화면 구현의 기준 문서다. 화면마다 목적, 구성, 표시 데이터, 사용자 행동, 상태를 정한다. 데이터 이름은 docs/glossary.md를 따른다.

- 기준 문서: docs/planning.md (차곡 기획초안 v0.8) 9장
- 화면에 서비스명이 필요하면 '차곡' 대신 `APP_NAME`을 쓴다. 서비스명은 아직 미정이다.
- 이 문서에 없는 화면, 버튼, 데이터를 추가해야 하면 구현 전에 먼저 질문한다.
- API 명세는 와이어프레임이 나온 뒤 이 문서의 '표시 데이터'와 '사용자 행동'을 기준으로 작성한다.

| 상태 | 보여줄 것 |
| --- | --- |

## S02 오늘

- 목적: 오늘 할 일을 보고 바로 완료한다. 앱을 열면 처음 보이는 화면이다.
- 진입: 하단 탭, 로그인 직후(목표 1개 이상)

| 구성 (위→아래) | 표시 데이터 |
| --- | --- |
| 날짜 | 오늘 날짜, 설정 아이콘. 아래 한 줄에 진행 현황 |
| 건물 띠 | 진행 중인 목표의 건물(그림 자리, 건물 이름, 공정 막대, 단계). 넘치면 가로로 넘긴다. 진행 중인 목표가 없거나 불러오지 못하면 숨긴다 |
| 안내 영역 (조건부) | 지난 할 일 안내, 집 업그레이드 가능 안내. 둘 다 있으면 지난 할 일 안내만 |
| 진행 현황 | 핵심 할 일 완료 수/핵심 할 일 수, 오늘 완료 수/오늘 할 일 수. 날짜 아래 줄에 쓴다 |
| 핵심 할 일 (최대 3개) | `Task.title`, 연결된 목표 이름, 완료 여부 |
| 일일 보너스 진행 | 일반 할 일 완료 수/`DAILY_BONUS_THRESHOLD`, 받음 여부 |
| 할 일 | 핵심이 아닌 오늘 할 일. 핵심 할 일과 중복 표시하지 않음 |
| 완료한 할 일 | 접힌 목록. 펼치면 오늘 완료한 할 일 |
| 할 일 추가 버튼 | 화면 아래쪽, 하단 탭 위 |

| 사용자 행동 | 결과 |
| --- | --- |
| 할 일 탭(체크) | 완료 처리. 알림 표시. 화면 이동 없음 |
| 알림의 실행 취소 | 완료 취소. 크레딧과 공사 진행 회수 |
| 할 일 제목 누르기 | S04 |
| 할 일 길게 누르기 또는 더보기 | 핵심으로 지정/해제, 날짜 바꾸기, 날짜 없이 보관 |
| 지난 할 일 안내 누르기 | 지난 할 일 목록. 항목마다 오늘로, 날짜 바꾸기, 날짜 없이 보관 |
| 할 일 추가 | S03 (수행 날짜 기본값 오늘) |
| 마을 보러 가기 | S05 |
| 건물 띠의 건물 누르기 | S05 |

완료 알림 문구 규칙

| 완료한 할 일 | 알림 |
| --- | --- |
| 핵심 할 일, 목표 연결 | '+20 크레딧 · 오피스 공사 진행' |
| 핵심 할 일, 목표 없음 | '+20 크레딧' |
| 일반 할 일, 목표 연결 | '오피스 공사 진행' |
| 일반 할 일, 목표 없음, 보너스 달성 전 | '오늘의 보너스 3/5' |
| 일일 보너스 달성 | '+20 크레딧 · 오늘의 보너스' |
| 건물이 골조 단계가 됨 | '오피스 골조가 올라갔어요' |

| 상태 | 보여줄 것 |
| --- | --- |
| 오늘 할 일 0개 | 목록 자리에 빈 화면 카드 (아래 'S02 빈 화면 카드'). 모달은 띄우지 않는다 |
| 로딩 | 목록 자리에 회색 줄 3개 |
| 핵심 할 일 3개가 이미 있음 | 4번째 지정 시 '핵심 할 일은 3개까지예요'와 교체할 항목 선택 |
| 지난 할 일 있음 | 안내 '지난 할 일 2개가 남아 있어요'. 오늘 목록에 자동으로 넣지 않음 |
| 오늘 할 일 모두 완료 | 완료 메시지와 '마을 보러 가기' 버튼 |
| 집 업그레이드 조건 충족 | 안내 '집을 넓힐 수 있어요'와 '마을 보러 가기' 버튼 |
| 어제 이전에 완료한 할 일 | 완료 취소 불가. 실행 취소 버튼 없음 |

핵심 할 일 규칙

| 상황 | 규칙 |
| --- | --- |
| 완료한 할 일 | 더보기 메뉴와 길게 누르기가 없다. 크레딧을 이미 받은 핵심 할 일을 해제하지 않기 위해서다 |
| 핵심 교체 시트 | 완료한 핵심 할 일은 교체 후보에서 뺀다. 모두 완료했으면 '오늘 핵심 할 일을 모두 마쳐서 바꿀 수 없어요' |
| 다른 날로 옮긴 핵심 할 일 | 옮긴 날짜의 핵심 할 일이 이미 3개면 그날의 핵심 교체 시트를 연다. 뺄 할 일을 고르거나 '일반 할 일로 옮기기', '그대로 두기'(옮기지 않음) |
| 날짜 없이 보관한 핵심 할 일 | 핵심 지정을 해제한다 |

### S02 빈 화면 카드

오늘 할 일이 0개일 때 목록 자리에 보여준다. 매번 닫아야 하는 모달 대신, 누르고 싶을 때만 누르는 카드다.

| 순서 | 구성 | 보여주는 조건 | 누르면 |
| --- | --- | --- | --- |
| 안내 | '오늘 할 일이 아직 없어요' | 항상 | - |
| 1 | 목표에서 가져오기: 날짜 없는 할 일 최대 3개와 '더 보기' | 진행 중 목표에 날짜 없는 할 일이 있을 때 | 항목을 누르면 수행 날짜가 오늘로. '더 보기'는 날짜 없는 할 일 전체 목록 |
| 2 | 빠른 추가 칩: 최대 `QUICK_TEMPLATE_DISPLAY_LIMIT`개 | 항상 | S16 |
| 3 | 직접 입력 | 항상 | S03 (날짜 기본값 오늘) |
| 4 | AI로 목표 만들기 | 진행 중 목표가 0개일 때 | S09 |

칩 정렬 순서

1. 최근에 사용자가 만든 할 일의 키워드 (`source = TEMPLATE`로 만든 할 일 기준, 최근 사용 순)
2. 사용자의 진행 중 목표 유형에 맞는 템플릿
3. 공통 템플릿 (정렬 순서 값 기준)

같은 키워드는 한 번만 보여준다.

### S02 지난 할 일 (바텀시트)

- 목적: 수행 날짜가 지난 할 일을 하나씩 정리한다. 정리하지 않고 닫아도 된다.
- 진입: S02 지난 할 일 안내 누르기

| 구성 (위→아래) | 표시 데이터 |
| --- | --- |
| 제목 | '지난 할 일 N개' |
| 목록 | `Task.title`, 연결된 목표 이름, 원래 수행 날짜. 오래된 날짜가 위 |
| 항목별 행동 | 오늘로, 날짜 바꾸기, 날짜 없이 보관 |

| 사용자 행동 | 결과 |
| --- | --- |
| 오늘로 | 수행 날짜를 오늘로 바꾼다. 목록에서 빠지고 오늘 화면에 보인다 |
| 날짜 바꾸기 | 날짜 선택 후 그 날짜로 옮긴다 |
| 날짜 없이 보관 | 수행 날짜를 없앤다 |
| 시트 내리기 | 닫힘. 남은 항목은 그대로 둔다 |

| 상태 | 보여줄 것 |
| --- | --- |
| 마지막 항목을 정리함 | 시트를 닫고 안내도 사라진다 |
| 저장 실패 | 항목을 그대로 두고 '저장하지 못했어요'와 재시도 |

## S16 빠른 추가 (바텀시트)

- 목적: 키워드와 수량만 골라 할 일을 만든다. AI를 호출하지 않는다.
- 진입: S02 빈 화면 카드의 칩

| 구성 (위→아래) | 내용 |
| --- | --- |
| 키워드 | 누른 칩의 이름. 예: 독서 |
| 단위 선택 | 템플릿에 단위가 2개 이상이면 표시. 예: 분 / 쪽 |
| 수량 선택 | 단위별 선택지 칩. 예: 10, 20, 30. 기본값이 선택된 상태 |
| 미리보기 | 만들어질 제목. 예: '독서 20분' |
| 연결 목표 | 목표 유형 템플릿일 때만 표시. 그 유형의 진행 중 목표가 하나면 자동 선택, 여러 개면 가장 최근 목표를 선택하고 바꿀 수 있음 |
| 매일 반복 토글 | 기본 해제 |
| 추가 버튼 | 키보드 없이 누를 수 있도록 화면 아래쪽 |

| 사용자 행동 | 결과 |
| --- | --- |
| 추가 | 제목 '{키워드} {수량}{단위}'로 오늘 할 일 생성 (`source = TEMPLATE`). 시트 닫힘 |
| 미리보기 제목 누르기 | 제목 직접 수정 |

| 상태 | 보여줄 것 |
| --- | --- |
| 템플릿 불러오기 실패 | 칩 대신 '직접 입력' 버튼만 |

크레딧은 일반 할 일과 같은 규칙을 따른다. 핵심 할 일 지정은 생성 후 오늘 화면에서 한다.

## S03 할 일 추가 (바텀시트)

- 목적: 제목 하나로 할 일을 빠르게 추가한다.
- 진입: S02, S12의 할 일 추가

| 구성 | 기본값 |
| --- | --- |
| 제목 입력 (필수) | 열리면 바로 키보드 포커스 |
| 날짜 칩 | 오늘 · 내일 · 날짜 선택 · 날짜 없음 중 하나. S02에서 열면 오늘, S12에서 열면 날짜 없음. 빠른 추가 칩은 두지 않는다 (2026-10-28 확정) |
| 목표 칩 | S12에서 열면 그 목표, S02에서 열면 없음 |
| 핵심 할 일 토글 | 해제. 날짜가 있을 때만 활성 |
| 추가 버튼 | 키보드 위에 붙어 있음 |

| 사용자 행동 | 결과 |
| --- | --- |
| 추가 | 할 일 생성. 시트는 열린 채로 입력칸만 비움 (연속 추가) |
| 시트 내리기 | 닫힘. 입력 중인 내용이 있으면 버림 확인 없이 닫는다 |

| 상태 | 보여줄 것 |
| --- | --- |
| 제목 비어 있음 | 추가 버튼 비활성 |
| 핵심 할 일 3개 있음 | 핵심 토글 비활성과 '핵심 할 일은 3개까지예요' |

## S04 할 일 상세

- 목적: 할 일을 수정하고 재계획한다.
- 진입: S02, S12에서 할 일 제목 누르기

| 구성 | 표시 데이터 |
| --- | --- |
| 제목 | `Task.title` (수정 가능) |
| 날짜 | `scheduledDate` 또는 날짜 없음 |
| 핵심 할 일 | `isCore` |
| 목표 | 연결된 목표 또는 없음 |
| 반복 | `recurrence` |
| 메모 | 선택 입력 |
| 하단 버튼 | 나누기, 삭제 |

| 사용자 행동 | 결과 |
| --- | --- |
| 날짜 바꾸기 | 날짜 선택. 이전 날짜 기록은 남음 |
| 날짜 없이 보관 | `scheduledDate = null` |
| 나누기 | 새 제목 2개 이상 입력 → 원래 할 일은 `SPLIT`, 새 할 일 생성 (원래 날짜, 목표 유지) |
| 삭제 | 확인 후 삭제. 완료한 할 일은 삭제해도 지급된 크레딧과 공사 진행을 회수하지 않는다 |

| 상태 | 보여줄 것 |
| --- | --- |
| 완료한 할 일 | 날짜, 핵심, 연결 목표 변경과 나누기 비활성 (목표와 나누기는 2026-10-28 확정). 위에 '오늘 완료했어요' 또는 '10월 27일에 완료했어요'. 당일이면 나누기 자리에 완료 취소 버튼 |
| 로딩 | 제목과 줄 자리에 회색 막대 |
| 불러오기 실패 | '할 일을 불러오지 못했어요'와 다시 시도 |
| 없는 할 일 (지웠거나 나눈 할 일) | '할 일을 찾을 수 없어요'와 '오늘로 가기' |
| 핵심 할 일 3개가 이미 있음 | 그 날짜의 핵심 교체 시트 (S02와 같음) |

S04 저장 방식 (2026-10-28 확정)

| 항목 | 규칙 |
| --- | --- |
| 저장 | 저장 버튼 없이 바꾸는 즉시 저장. 제목과 메모는 입력칸을 벗어날 때 저장 |
| 제목 비우기 | 비운 채 벗어나면 원래 제목으로 돌아간다 |
| 저장 실패 | 바꾼 값을 되돌리고 알림 '저장하지 못했어요'와 다시 시도 |
| 나누기, 삭제 뒤 | 이전 화면(S02, S12)으로 돌아가 알림 '할 일 3개로 나눴어요' / '할 일을 지웠어요' |

## S05 마을

- 목적: 실행이 쌓인 결과를 보고, 집으로 들어간다.
- 진입: 하단 탭, S02의 '마을 보러 가기'

| 구성 | 표시 데이터 |

| 상단 | 크레딧 잔액 |

| 건물 이름표 | 건물을 누르면 목표 이름과 공사 진행 표시 |

| 사용자 행동 | 결과 |
| --- | --- |
| 집 누르기 | S06 |
| 건물 누르기 | 이름표 표시. 이름표를 누르면 S12 |

| 상태 | 보여줄 것 |
| --- | --- |
| 목표 0개 | 집만 있음과 'AI로 목표 만들기' 버튼 |

## S06 집 내부

- 목적: 가구를 사서 설치하고 집을 넓힌다.
- 진입: S05에서 집 누르기

| 구성 | 표시 데이터 |
| --- | --- |
| 상단 | 집 단계 이름, 크레딧 잔액 |
| 방 그림 | 집 단계별 배경, 슬롯(`Slot`)과 설치된 가구(`Placement`) |
| 업그레이드 영역 | 보유 가구 수/필요 수, 크레딧 잔액/비용, 업그레이드 버튼 |

| 사용자 행동 | 결과 |
| --- | --- |
| 빈 슬롯(+) 누르기 | S07 (그 슬롯에 놓을 수 있는 가구만) |
| 설치된 가구 누르기 | 바꾸기(S07), 빼기 (뺀 가구는 보유 상태로 남고, 업그레이드 조건의 가구 수도 줄지 않음) |
| 업그레이드 | 확인 후 다음 단계로. 가구는 그대로 가져가고 슬롯이 늘어남 |

| 상태 | 보여줄 것 |
| --- | --- |
| 빈 슬롯 | 슬롯 위치에 + 표시 |
| 업그레이드 조건 미충족 | 진행 표시 두 줄 (가구 2/3, 크레딧 210/300), 버튼 비활성 |
| 업그레이드 조건 충족 | 버튼 활성 |
| 최고 단계 | 업그레이드 영역 대신 '가장 넓은 집이에요' |
| 잔액 마이너스 | 잔액을 진한 주황 글자와 '−'로 표시하고 이유 설명. 구매 불가. 빨강은 쓰지 않는다 |

| 구성 | 표시 데이터 |

| --- | --- |

| 보유 가구 설치 | 크레딧 차감 없이 설치 |

| 상태 | 보여줄 것 |
| --- | --- |
| 크레딧 부족 | 가격 표시, 버튼 비활성, '핵심 할 일 2개를 더 하면 살 수 있어요' (부족 크레딧 ÷ `CORE_TASK_CREDIT` 올림) |

## S09 목표 입력 (AI 분해 1)

- 목적: 목표 제목만 입력하고 AI에게 할 일 초안을 받는다.
- 진입: 첫 로그인(목표 0개), S08 새 목표, 빈 화면의 'AI로 목표 만들기'

| 구성 | 내용 |
| --- | --- |
| 안내 문구 | '이루고 싶은 목표를 적어주세요' |
| 목표 제목 (필수) | 예시 placeholder '백엔드 개발자로 취업하기' |
| 기한 (선택) | 날짜 선택 |
| 지금 상황 (선택) | 한 줄 입력. 예: '자소서 초안만 있어요' |
| 남은 횟수 | '오늘 7번 더 쓸 수 있어요' |
| 하단 버튼 | 할 일 추천받기 |
| 보조 버튼 | 직접 입력하기, (첫 진입일 때만) 나중에 하기 |

| 사용자 행동 | 결과 |
| --- | --- |
| 할 일 추천받기 | 생성 중 상태 → 성공하면 S10 |
| 직접 입력하기 | S11 (입력한 제목 유지) |
| 나중에 하기 | S02 |

| 상태 | 보여줄 것 |
| --- | --- |
| 제목 비어 있음 | 추천받기 버튼 비활성 |
| 생성 중 | 진행 표시와 취소 버튼. 입력값 유지 |
| 실패, 시간 초과 | 'AI가 응답하지 않아요'와 다시 시도, 직접 입력 버튼 |
| 하루 호출 상한 도달 | '오늘 AI 사용을 모두 썼어요'와 직접 입력 버튼. 추천받기 비활성 |

## S10 할 일 초안 선택 (AI 분해 2)

- 목적: AI가 만든 할 일 중 쓸 것만 고른다.
- 진입: S09 성공

| 구성 (위→아래) | 표시 데이터 |
| --- | --- |
| 목표 요약 | 목표 제목, 추천된 건물 종류(바꿀 수 있음) |
| 선택 전환 버튼 | '모두 선택' 또는 '모두 해제' |
| 초안 목록 | `TaskDraft.title` 5~10개, 체크박스 |
| 하단 버튼 | 'N개 추가하기' |
| 보조 버튼 | 다시 만들기 |

초안 선택 규칙

| 선택 상태 | 선택 전환 버튼 | 누르면 |
| --- | --- | --- |
| 0개 | 모두 선택 | 전부 선택 |
| 일부 | 모두 선택 | 나머지까지 전부 선택 |
| 전부 | 모두 해제 | 전부 해제 |

| 사용자 행동 | 결과 |
| --- | --- |
| 초안 체크 | 선택 상태 변경 |
| 초안 제목 누르기 | 그 자리에서 제목 수정 |
| 건물 종류 바꾸기 | 5개 중 선택 |
| N개 추가하기 | 목표와 고른 할 일 생성(날짜 없음), 건물 터 생성 → S12 |
| 다시 만들기 | 하루 호출 횟수 차감 후 새 초안. 현재 선택은 사라짐 |
| 뒤로 가기 | S09 (입력값 유지). 초안은 저장되지 않음 |

| 상태 | 보여줄 것 |
| --- | --- |
| 초안 도착 직후 | 모두 해제 상태 |
| 선택 0개 | 추가 버튼 비활성 |
| 다시 만들기 중 | 목록 자리에 진행 표시 |
| 하루 호출 상한 도달 | 다시 만들기 비활성 |

| 건물 종류 | 5개 중 선택 (필수) |
| 할 일 입력 | 한 줄씩 추가. 0개여도 됨 |

| --- | --- |
| 목표 만들기 | 목표, 할 일, 건물 터 생성 → S12 |

| --- | --- |
| 제목 또는 건물 종류 비어 있음 | 버튼 비활성 |

## S12 목표 상세

- 목적: 목표에 연결된 할 일을 관리하고, 목표를 완료하거나 보관한다.
- 진입: S08, S05 건물 이름표, S10, S11

| 구성 (위→아래) | 표시 데이터 |
| --- | --- |
| 건물 그림 | `BuildingType`, `BuildingStage` |
| 목표 정보 | 제목, 기한, 완료 조건, 할 일 진행 (완료 수/전체 수) |
| 날짜 있는 할 일 | 날짜순 |
| 날짜 없는 할 일 | 목록 |
| 완료한 할 일 | 접힌 목록 |
| 하단 버튼 | 할 일 추가, 더보기(목표 수정, 목표 완료, 보관) |

| 사용자 행동 | 결과 |
| --- | --- |
| 할 일 체크 | 완료 처리 (S02와 같은 알림) |
| 할 일 '오늘로' | 수행 날짜를 오늘로 |
| 할 일 추가 | S03 (목표 기본 선택, 날짜 없음) |
| AI로 할 일 추가 | S09와 같은 흐름. 결과는 이 목표에 추가 |
| 목표 완료 | 확인. 남은 할 일은 '그대로 두기 / 날짜 없이 보관 / 삭제' 중 선택 → 건물 완성 |
| 보관 | 확인 후 보관. 건물 공사 중지 |

| 상태 | 보여줄 것 |
| --- | --- |
| 할 일 0개 | 'AI로 할 일 추가', '직접 추가' 버튼 |
| 연결된 할 일 모두 완료 | '목표를 완료할까요?' 안내. 자동 완료하지 않음 |
| 기한 지남 | 기한 변경, 보관 버튼. 실패 표시 없음 |
| 보관한 목표 | 상단에 '보관한 목표예요'와 다시 진행하기 버튼 |
